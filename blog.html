why i love HTML and CSS

published on the 6th november 2026 by Zara

HTML and CSS are the backbone of web development. They allow me to create beautiful and functional websites. I enjoy the process of designing layouts, styling elements, and bringing my ideas to life on the web.

HTML was created in 1993. Today every single website still uses it. Without HTML, there would be no headings, images or buttons. It is the skeleton of the web. Modern CSS features like Flexbox and CSS Grid allow a single HTML file to instantly re-arrange its layout automatically. This allows websites to shift beautifully from a massive desktop monitor to a tiny smartphone screen without rewriting any text content
